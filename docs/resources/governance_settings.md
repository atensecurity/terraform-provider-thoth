# thoth_governance_settings

Manages tenant compliance declarations, risk policy, secret broker controls, and model routing.

`compliance_profile` and `regulatory_regimes` select legacy onboarding packs. Their implicit
SOC 2 default never activates executable compliance. Set `declared_regulatory_regimes` and
an explicit `compliance_enforcement_mode` to govern every current and future tenant agent.
This extends the existing settings resource while keeping legacy pack behavior separate.

## Example Usage

```terraform
resource "thoth_governance_settings" "assessment" {
  declared_regulatory_regimes  = ["fedramp", "cmmc_l1", "iso_27001"]
  compliance_enforcement_mode = "observe"
}
```

Accepted names are `soc2`, `hipaa`, `gdpr`, `fedramp`, `sec_cftc`, `finra`, `cmmc_l1`,
`iso_27001`, `iso_42001`, and `hitech`. Case, whitespace, `_`, `-`, and `/` separators
are ignored; input spellings remain in Terraform state. HITECH and HIPAA are separate
regimes. Unknown names and equivalent duplicates are plan-time errors.

`compliance_coverage`, `canonical_regimes`, `regimes_without_controls`, and release hashes
are known in the first plan when the declaration is known. Coverage is an author
classification, not an assessor-approved mapping or a claim of regulatory conformance.
ISO 27001, ISO 42001, and HITECH currently have no executable controls. Their coverage
gaps remain visible in both modes and add no per-action restriction.

Observe records advisory findings without relaxing or adding to independent authorization.
Changing `compliance_enforcement_mode` to `enforce` adds non-grantable compliance
restrictions for all tenant agents within 1000 ms. Evidence-based `UNRESOLVED` findings
block in enforce mode; structural gaps do not. Review evidence gaps and observe findings
before changing mode. An enforcement warning accompanies the plan diff.

Apply first verifies that the running enforcer matches the provider's catalogue and
evaluator identities and that atomic declaration history is supported. A mismatch or
unavailable capability fails before any settings mutation. Reconcile provider and server
versions and create a new plan before retrying.

Omitting a declaration that was never managed preserves any external declaration.
Removing a previously managed declaration (or setting `[]` and removing its mode) clears
it using its prior revision. Removing mode while leaving regimes active is an error.
Destroy clears only the managed declaration and mode, preserving legacy settings; a
legacy-only resource destroy is a no-op. Stale revisions fail without overwriting a newer
declaration. Import does not adopt an external compliance declaration automatically;
add explicit declaration and mode configuration to take ownership.

`extra_settings_json` cannot contain executable compliance fields, revision controls,
identity hashes, or coverage fields. Use the typed attributes so the plan remains accurate.

See `examples/compliance-activation/` for the full example and actual local fixture plan
outputs, including the observe-to-enforce diff. The fixture never contacts a real tenant.

## Schema

### Optional

- `compliance_enforcement_mode` (String) Required with a nonempty declaration: observe evaluates and records advisory findings while preserving independent authorization; enforce adds non-grantable restrictions for DENY, STEP_UP and evidence-based UNRESOLVED. Changing mode affects every tenant agent within 1000 ms. Structurally unserved regimes report coverage gaps and add no action restriction.
- `compliance_profile` (String) Compliance profile (soc2, healthcare, financial, public_sector, privacy, ai_governance).
- `declared_regulatory_regimes` (Set of String) Explicit executable compliance declaration for all current and future tenant agents. Case and separators are ignored. Removing a managed declaration or setting [] clears it. Legacy profile defaults never activate this binding.
- `extra_settings_json` (String) Additional JSON object merged into the outgoing settings payload for forward compatibility.
- `model_router_allowed_models` (List of String) Allowed model names allowlist.
- `model_router_allowed_providers` (List of String) Allowed model providers allowlist.
- `model_router_default_model` (String) Default model name.
- `model_router_default_provider` (String) Default model provider.
- `model_router_enabled` (Boolean) Enable model routing policy controls.
- `model_router_failover_providers` (List of String) Failover provider order.
- `regulatory_regimes` (List of String) Explicit regulatory regimes for onboarding baseline auto-pack loading (for example: soc2, hipaa, gdpr, fedramp, sec_cftc). Legacy packs only; defaults to SOC2 when unset. Does not activate executable compliance.
- `secret_broker_allowed_hosts` (List of String) Allowed host patterns for secret broker.
- `secret_broker_auth_bindings_json` (String) JSON array of auth binding objects (host_pattern, header, secret_ref, prefix).
- `secret_broker_enabled` (Boolean) Enable secret broker policy enforcement.
- `secret_broker_fail_on_missing_secret` (Boolean) Fail governed calls when referenced secret is unavailable.
- `secret_broker_provider` (String) Secret broker provider slug.
- `secret_broker_strict_endpoint_mode` (Boolean) Require endpoint registration for secret resolution.
- `shadow_critical` (String) Default action for critical risk events.
- `shadow_high` (String) Default action for high risk events.
- `shadow_low` (String) Default action for low risk events.
- `shadow_medium` (String) Default action for medium risk events.
- `tool_risk_overrides` (Map of String) Tool-specific risk tier overrides.

### Read-Only

- `canonical_regimes` (Set of String) Canonical declared regimes. Known during planning for known declarations.
- `compliance_catalogue_sha256` (String) Pinned catalogue identity. Apply fails before mutation if the running catalogue differs.
- `compliance_coverage` (Attributes Map) Per-regime author classifications from the pinned executable catalogue, available before first apply. These counts are not a regulatory conformance assessment. (see [below for nested schema](#nestedatt--compliance_coverage))
- `compliance_evaluator_sha256` (String) Pinned evaluator identity, checked before mutation.
- `compliance_revision` (Number) Revision used for optimistic concurrency. A stale apply or destroy fails without replacing a newer declaration.
- `id` (String) Terraform resource identifier (tenant ID).
- `propagation_max_ms` (Number) Maximum positive cache lifetime for declaration changes: 1000 milliseconds.
- `regimes_without_controls` (Set of String) Declared regimes with no executable controls. These are coverage gaps, never a clean result or a per-action restriction.
- `tenant_id` (String) Tenant ID resolved from provider configuration.
- `updated_at` (String) Last update timestamp returned by GovAPI.
